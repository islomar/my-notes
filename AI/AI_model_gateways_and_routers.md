# AI model gateways and routers

## General options

- [OmniRoute](#omniroute)
- [Routerly](#routerly)
- [LiteLLM](#litellm)
- [NVIDIA NeMo Switchyard](https://github.com/NVIDIA-NeMo/Switchyard)
  - Switchyard lets LLM applications route traffic across models and providers while preserving native OpenAI and Anthropic API compatibility - enabling flexible model selection, benchmarking, and cost/performance optimization.
- [Claude Code workflows](https://code.claude.com/docs/en/workflows)
- **OpenCode**
  - OpenCode can **route work to different models/providers automatically through agents/subagents**: https://opencode.ai/docs/agents/
    - Use the `description` option to provide a brief description of what the agent does and when to use it.
  - Additional option: [opencode-model-router](https://github.com/marco-jardim/opencode-model-router)
